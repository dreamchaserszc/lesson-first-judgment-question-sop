# 单课时判断题设计与审核

## 核心定位

先吃透本课讲什么、不讲什么，再围绕本课关键理解边界设计**数学严谨、短小地道、老师上台就能顺口念出来**的判断题：

```text
好判断题 = 本课核心正确命题
         + 一个学生真会混淆的边界改变（或反直觉但合法的变形）
         + 课内可执行的简明证明、计算或反例
         + 自然地道的初中课堂汉语
```

不预设固定题数，不套母题卡/错因树/配额模板，更不为防极端抬杠把题干写成拗口的“法条说明书”或“木偶剧本”。

## 默认双分支与可选微变模式

1. **默认双分支输出（全课巡检）**：完整读取 `references/dual-branches.md`，同时生成 **第一类：知识辨析型** 与 **第二类：想法辨析型** 供教师挑选。
   - **知识辨析型**：聚焦概念、法则、性质的关键条件与适用边界，短句直判（一般 ≤35 字）。
   - **想法辨析型**：聚焦具体学习步骤中“依据能否推出结论”（一般 ≤55 字）。**算式/图形直觉题优先直接写客观推理句，不强行每题套“小明认为”**；确需人物情境时，想法必须贴合真学生直觉，严禁编造绕弯假脑回路、严禁旁白自曝错因剧透答案、严禁借人物背诵标准教案、严禁句尾复读“他的想法正确”。
2. **可选单点微变模式（按需触发）**：当用户明确要求“围绕某一个公式/定义通过微小变化打透”时，围绕同一基础素材每次只微调一处（符号、系数、指数、顺序）形成紧凑对比串，仅删去判断依据完全重复的机械换数题。

## 共享基础与术语准入

1. 读取 `references/lesson-first-foundation.md`（套件环境兼容 `../_shared/lesson-first-math/references/lesson-first-foundation.md`）与 `references/terminology-policy.md`。
2. 有明确课时标识时，优先查找 `references/lesson-lexicons/`（或套件共享层 `../_shared/lesson-first-math/references/lesson-lexicons/`）中匹配的 `CURRENT_VERIFIED` 课时标准词表；学生题干只使用本课材料明示词、同版本有据前置词或教师批准词（如七上未学“实数”时绝不写“对任意实数”，六下起始课未学“概率/必然事件”时绝不越界使用）。
3. **宁缺毋滥原则**：若禁用某专业词后，普通话改写变成同义反复的车轱辘话（如“确定事件都是确定会发生的事件”），或者无图几何题需要两层以上空间修饰才能把位置描清楚，**直接换具体例子或淘汰该题，绝不硬拗怪话**。

## 生成与审核五步流程

1. **锁定课时理解卡**：根据课时标题、教师说明或教材/PPT材料，列出主要内容、包含范围、排除范围、证据依据与 AI 推定项，作为教师可见输出的第一部分。
2. **提取独立诊断点（不预设题数）**：把本课核心内容拆成若干互不重叠、确实值得课堂辨析的理解边界（知识组关注概念/性质边界，想法组关注具体步骤中的直觉滑坡）。有几个真正有价值的边界就准备几道题，不凑“6道/8道”槽位，也不配平两组题数或真假比例。
3. **设定组首约定并起草候选**：
   - 代数含字母受限式可在大题导语统一写一句自然前提（如 `除专门考查取值条件外，题中字母均取使原式有意义的值`），免去单题重复刷屏限定词。
   - 为每题同步写好课内证明或简洁反例，确保唯一真值。
4. **执行质量门与独立「口语脱敏重写关」（关键步，禁止走过场）**：
   - 完整对照 `references/quality-gates.md` 核查边界、真值、反例与术语。
   - **强制脱稿朗读重写**：逐题以初中老师口吻通读，砍掉法条式限定词、双重否定绕口令、括号免责补丁、生硬人物套话与剧透旁白。凡改不顺口的题一律淘汰。
5. **组内去重、删除测试与跨组提示**：
   - 组内删去认知动作重复的题；跨组若同一知识点同时保留了“规则短句版”和“具体想法版”，在教师说明末尾简短标注“可二选一”。

## 默认教师可见输出结构

按以下清晰顺序直接呈现（详见 `references/output-schema.md` 与 `references/count-formation.md`，学生题干不用表格承载）：

1. **课时理解卡**（课题、主要内容、包含范围、不包含范围、依据与待核对项、状态 `READY | PENDING_JUDGMENT | INSUFFICIENT_INPUT`）
2. **学生版**
   - 简短作答导语（含必要的组首课堂约定）
   - **第一类：知识辨析型**（题号 ＋ 干净陈述 ＋ `（　　）`）
   - **第二类：想法辨析型**（题号 ＋ 自然推理或情境想法 ＋ `（　　）`，无句尾“他的想法正确”尾巴）
3. **教师版答案与简析**（按两类列出题号、答案 `√/×`、简明课内依据或具体反例）
4. **选用提示**（仅在存在跨组“二选一”题目或需说明边界风险时简短给出）
