# 判断题文件落盘与诚实留痕规则

1. **纯聊天模式不建目录**：用户在对话中请求出题时，直接在聊天中输出“课时理解卡＋学生版＋教师版＋选用提示”，不擅自创建运行文件夹。
2. **文件/项目模式极简落盘**：当用户指定输出目录或学习单流水线需要存档时，只保留真正有价值的三份核心文件，不再建立 7 层空转阶段子目录：
   - `判断题_学生版.md`
   - `判断题_教师版.md`
   - `判断题包.json`（遵循 `output-schema.md` 的 `v2.1` 轻量结构）
3. **严禁脚本造假 `PASS`**：
   - `判断题包.json` 中的 `spoken_rewrite_log` 必须如实记录本轮在「口语脱敏重写关」中真正重写或淘汰掉的拗口初稿句。
   - **严禁**编写打包脚本批量硬塞 `PASS_NO_CHANGE` 或把定稿题干原样复制充当审核记录。
4. **词表唯一归口**：首次为新课时沉淀已核验标准词表时，统一调用 `scripts/promote_lesson_lexicon.py` 写入正式词表目录（独立安装时写入 `references/lesson-lexicons/`，套件环境自动写入共享层 `../../_shared/lesson-first-math/references/lesson-lexicons/`），不在运行目录重复存放第二份词表副本。
